# Stash 🐹: хомяк-кладовщик для Claude

Telegram-бот, которому ты пересылаешь всё, что нашёл для Claude: skills, плагины, MCP-серверы, CLI-утилиты, сервисы, посты и PDF.
Хомяк Стэш набивает ими щёки. Он разбирается, что это, предлагает план установки, ставит по кнопке
и ворчливо напоминает о том, что ты натаскал и забыл.

> «Помнишь claude-seo (#1)? Неделю лежит. Зачем-то же тащили?» (Стэш)

## Что умеет
- **Принимает что угодно**: ссылки, пересланные посты (с картинками и скрытыми ссылками), PDF (вытаскивает текст и ссылки), файлы.
- **Разбирается**. Агент на [Claude Agent SDK](https://docs.claude.com/en/api/agent-sdk/overview) читает материал и определяет тип
  (skill, плагин, MCP, CLI, SaaS). Потом пишет план установки для Claude Code на macOS, оценивает риск и проверяет, не стоит ли это у тебя уже.
- **Ставит только по кнопке**: 🐹 Разгрузить щёки · 🌰 Припрятать · 💨 Выплюнуть.
- **Напоминает**. Каждый вечер достаёт из кладовки один забытый запас, по понедельникам присылает ревизию всего.
- **`/norka`** показывает статистику и ранг хомяка: от 🐣 Хомячка-новичка до 👑 Легенды норки.

Команды: `/list`, `/norka`, `/all`, `/show N`, `/install N`, `/reanalyze N`.

## Два режима

| | 🏠 Локальный | ☁️ GitHub Actions + грузчик на Mac |
|---|---|---|
| Где живёт хомяк | на твоём Mac | в GitHub Actions твоего форка |
| Скорость ответа | сразу | 5–15 минут (GitHub запускает по расписанию) |
| Работает, когда Mac выключен | нет | да: принимает, разбирает, напоминает |
| Кто ставит | сам хомяк | грузчик `mac_helper.py` на Mac, когда тот включён |
| Стоимость | 0 | 0 (публичный репозиторий) |

В обоих режимах Claude работает через твою подписку (`claude setup-token`) или через `ANTHROPIC_API_KEY`.

## Установка

### 0. Общее
1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и получи токен. Свой user id узнай у [@userinfobot](https://t.me/userinfobot).
2. Нужны [uv](https://docs.astral.sh/uv/) и [Claude Code](https://claude.com/claude-code), в котором ты залогинен.
3. Сделай форк репозитория (для облачного режима) или просто клонируй его:
```bash
git clone https://github.com/<ты>/stash-hamster-bot && cd stash-hamster-bot
cp .env.example .env    # впиши TELEGRAM_BOT_TOKEN и TELEGRAM_ALLOWED_USER_ID
uv sync
```

### 🏠 Локальный режим
```bash
uv run python bot.py                 # проверить
zsh scripts/install_mac.sh local     # автозапуск через launchd
```

### ☁️ Облачный режим (GitHub Actions)
Работает в твоём **форке**: секреты и каталог будут только у тебя.
```bash
gh auth login                        # если ещё не
zsh scripts/cloud_setup.sh
```
Скрипт делает следующее:
- создаёт ключ шифрования и кладёт секреты в GitHub Secrets твоего форка;
- просит токен `claude setup-token`;
- шифрует каталог и кладёт его в ветку `norka-data`;
- выключает локального бота и ставит на Mac грузчика, который запускается раз в 2 минуты;
- запускает первый прогон.

Посмотреть прогоны: `gh run list --workflow=stash.yml`.

## Как устроено
```
Telegram ──► GitHub Actions (раз в 5 мин): cloud_run.py
                 │  разбор: Claude Agent SDK (только чтение: WebFetch, WebSearch, Read)
                 │  кнопка «Разгрузить» ─► статус approved
                 ▼
          ветка norka-data: norka.enc (каталог, зашифрован Fernet-ключом STASH_DATA_KEY)
                 ▲            results/*.enc (отчёты грузчика)
                 │
          Mac: mac_helper.py (launchd, раз в 2 мин): ставит approved через Claude Agent SDK
               (Bash, запись в ~/.claude), пишет отчёт в Telegram и в results/
```

| Файл | Что делает |
|---|---|
| `bot.py` | хендлеры Telegram, общие для обоих режимов |
| `persona.py` | характер и все реплики Стэша |
| `agent.py` | разбор и установка через Claude Agent SDK |
| `storage.py` | каталог (JSON) |
| `cloud_run.py` | один прогон в Actions |
| `mac_helper.py` | грузчик на Mac |
| `crypto_store.py` | шифрование каталога |

## Безопасность
- Бот отвечает только на `TELEGRAM_ALLOWED_USER_ID`.
- Анализ идёт **только на чтение**. Установку с доступом к Bash агент запускает только после твоей кнопки.
  Запрет на sudo и удаление файлов задан в промпте, жёстко он не проверяется, поэтому смотри поле «Риск» перед установкой.
- В публичном репозитории каталог лежит только в зашифрованном виде. Не теряй `STASH_DATA_KEY` из `.env`.
- Файлы, присланные в облачном режиме, живут только во время прогона. Для установки агент использует ссылки из материала.

## Ограничения облачного режима
- GitHub не гарантирует точное время запуска по расписанию, задержки 5–15 минут нормальны.
- В публичном репозитории GitHub отключает расписание после 60 дней без активности.
  Если запасы долго не меняются, включи обратно: `gh workflow enable stash.yml`.
- Держать постоянно работающего бота на Actions — серая зона в правилах GitHub. Если нужны мгновенные ответы,
  используй локальный режим.
