# Stash 🐹: хомяк-кладовщик для Claude

Telegram-бот, которому ты пересылаешь всё, что нашёл для Claude: skills, плагины, MCP-серверы, CLI-утилиты, сервисы, посты и PDF.
Хомяк Стэш набивает ими щёки. Он разбирается, что это, предлагает план установки, ставит по кнопке
и ворчливо напоминает о том, что ты натаскал и забыл.

> «Помнишь claude-seo (#1)? Неделю лежит. Зачем-то же тащили?» (Стэш)

## Что умеет
- **Принимает что угодно**: ссылки, пересланные посты (с картинками и скрытыми ссылками), PDF (вытаскивает текст и ссылки), файлы.
- **Разбирается**. Агент на [Claude Agent SDK](https://docs.claude.com/en/api/agent-sdk/overview) читает материал и определяет тип
  (skill, плагин, MCP, CLI, SaaS). Потом пишет план установки для Claude Code на macOS, оценивает риск и проверяет, не стоит ли это у тебя уже.
- **Ставит только по кнопке**: 🐹 Разгрузить щёки · 🌰 Припрятать · 💨 Выплюнуть.
- **Напоминает**. Каждый вечер достаёт из кладовки один забытый запас, по понедельникам присылает ревизию всего.
- **`/norka`** показывает статистику и ранг хомяка: от 🐣 Хомячка-новичка до 👑 Легенды норки.

- **🏠 Норка-приложение** (Telegram Mini App, кнопка «🐹 Норка» у поля ввода или `/app`). Там видно всё,
  что стоит на Mac: плагины, личные скиллы, MCP. У каждого написано по-русски, зачем он нужен и что умеет.
  Там же всё, что ждёт установки, с инструкцией, риском и кнопками «Установить» и «Выплюнуть». Есть поиск.
  Работает в мгновенном режиме, открыть её может только владелец (проверяется подпись Telegram).

- **🎙 Голосовые**: надиктуй «найди плагин для монтажа видео» — Whisper расшифрует, хомяк найдёт и разберёт.
- **🔎 Поиск по норке в чате**: `/find seo` или «? что есть для видео» — ответ по установленному и каталогу.
- **⬆️ Обновления**: раз в неделю сверяет версии плагинов с маркетплейсами (и git-скиллы), обновляет из норки в один клик.
- **🧹 Уборка**: дубли, пересечения, неиспользуемое (по истории Claude Code), битое — с бэкапом в Корзину.
- **💾 Резервные копии**: раз в день зашифрованная норка в iCloud Drive (`Stash-backups`, последние 30).

Команды: `/app`, `/find`, `/list`, `/norka`, `/all`, `/show N`, `/install N`, `/skip N`, `/reanalyze N`, `/cleanup`, `/update`, `/remove`, `/replace N`.

Разработка: `uv sync --extra voice && uv run pytest && node tests/check_worker.mjs` · CI гоняет тесты на каждый push и PR.

## Два режима

| | 🏠 Локальный | ☁️ GitHub Actions + грузчик на Mac |
|---|---|---|
| Где живёт хомяк | на твоём Mac | в GitHub Actions твоего форка |
| Скорость ответа | сразу | 5–15 минут (GitHub запускает по расписанию) |
| Работает, когда Mac выключен | нет | да: принимает, разбирает, напоминает |
| Кто ставит | сам хомяк | грузчик `mac_helper.py` на Mac, когда тот включён |
| Стоимость | 0 | 0 (публичный репозиторий) |

В обоих режимах Claude работает через твою подписку (`claude setup-token`) или через `ANTHROPIC_API_KEY`.

## Установка

### 0. Общее
1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и получи токен. Свой user id узнай у [@userinfobot](https://t.me/userinfobot).
2. Нужны [uv](https://docs.astral.sh/uv/) и [Claude Code](https://claude.com/claude-code), в котором ты залогинен.
3. Сделай форк репозитория (для облачного режима) или просто клонируй его:
```bash
git clone https://github.com/<ты>/stash-hamster-bot && cd stash-hamster-bot
cp .env.example .env    # впиши TELEGRAM_BOT_TOKEN и TELEGRAM_ALLOWED_USER_ID
uv sync
```

### 🏠 Локальный режим
```bash
uv run python bot.py                 # проверить
zsh scripts/install_mac.sh local     # автозапуск через launchd
```

### ☁️ Облачный режим (GitHub Actions)
Работает в твоём **форке**: секреты и каталог будут только у тебя.
```bash
gh auth login                        # если ещё не
zsh scripts/cloud_setup.sh
```
Скрипт делает следующее:
- создаёт ключ шифрования и кладёт секреты в GitHub Secrets твоего форка;
- просит токен `claude setup-token`;
- шифрует каталог и кладёт его в ветку `norka-data`;
- выключает локального бота и ставит на Mac грузчика, который запускается раз в 2 минуты;
- запускает первый прогон.

Посмотреть прогоны: `gh run list --workflow=stash.yml`.

### ⚡ Мгновенный режим (Cloudflare Worker, бесплатно)
Без него облачный хомяк отвечает раз в 5–15 минут. С ним бесплатный Cloudflare Worker принимает сообщения
Telegram, **за секунду** отвечает «🐹 Хап!», снимает «часики» с кнопок и сразу будит GitHub Actions.
Карточка приходит примерно через минуту.
```bash
zsh scripts/instant_setup.sh
```
Скрипт логинит тебя в Cloudflare, создаёт очередь (D1), выкладывает Worker и просит токен GitHub
с одним правом: **Actions: Read and write** на этот репозиторий. Потом подключает webhook Telegram.
После этого расписание нужно только для напоминаний: раз в 15 минут.

## Как устроено
```
Telegram ──► Cloudflare Worker: «🐹 Хап!» за 1 сек, апдейт в очередь D1, будит workflow
                 │
                 ▼
             GitHub Actions: cloud_run.py (забирает очередь; ещё раз в 15 мин по расписанию)
                 │  разбор: Claude Agent SDK (только чтение: WebFetch, WebSearch, Read)
                 │  кнопка «Разгрузить» ─► статус approved
                 ▼
          ветка norka-data: norka.enc (каталог, зашифрован Fernet-ключом STASH_DATA_KEY)
                 ▲            results/*.enc (отчёты грузчика)
                 │
          Mac: mac_helper.py (launchd, раз в 2 мин): ставит approved через Claude Agent SDK
               (Bash, запись в ~/.claude), пишет отчёт в Telegram и в results/
```

| Файл | Что делает |
|---|---|
| `bot.py` | хендлеры Telegram, общие для обоих режимов |
| `persona.py` | характер и все реплики Стэша |
| `agent.py` | разбор и установка через Claude Agent SDK |
| `storage.py` | каталог (JSON) |
| `cloud_run.py` | один прогон в Actions |
| `mac_helper.py` | грузчик на Mac |
| `crypto_store.py` | шифрование каталога |
| `worker/` | Cloudflare Worker: мгновенный режим и норка-приложение (`worker/src/app.html`) |
| `inventory.py` | опись установленного на Mac + русские описания (кеш `data/ru_cache.json`) |
| `tgfmt.py` | markdown агента → читаемый HTML для Telegram |

## Безопасность
Всё, что ты присылаешь (посты, страницы, PDF, репозитории), считается недоверенным: там может быть инструкция для ИИ.

- **Доступ.** Бот отвечает только на `TELEGRAM_ALLOWED_USER_ID`. Worker проверяет секретный заголовок Telegram,
  а норка-приложение — подпись Telegram (`initData`); очередь и опись закрыты отдельными ключами.
- **Разбор** идёт без доступа к файлам и командам: у агента есть только чтение веб-страниц и поиск.
- **Установка** запускается только по твоей кнопке и идёт в песочнице Claude Code (macOS seatbelt):
  - писать можно только в рабочую папку `data/work` и кеши пакетных менеджеров;
  - читать нельзя ключи и секреты: `~/.ssh`, `~/.aws`, `~/.claude.json`, `.env` бота, каталог, историю shell, данные браузеров;
  - скиллы агент собирает в `data/work/out/`, а в `~/.claude` их переносит код бота (нужен `SKILL.md`, без ссылок, старая версия уходит в Корзину);
  - `git clone`, `claude plugin …`, `claude mcp add …`, `brew install …` агент сам не запускает: он просит инструмент `host_run`,
    который сверяет команду с белым списком и выполняет её без оболочки (никаких `;`, `&&`, `|`, подстановок).
- **Что остаётся на тебе.** Плагин или пакет, который ты одобрил, выполняет свой код установки (`brew install`, плагины Claude).
  Смотри поля «Риск» и «План» перед кнопкой. `sudo` агент не использует никогда: такие шаги он отдаёт тебе.
- **Каталог** в публичном репозитории лежит только в зашифрованном виде. Не теряй `STASH_DATA_KEY` из `.env`.
- **Логи** GitHub Actions публичны, поэтому в облаке в них нет содержимого находок.

## Ограничения облачного режима
- GitHub не гарантирует точное время запуска по расписанию, задержки 5–15 минут нормальны.
- В публичном репозитории GitHub отключает расписание после 60 дней без активности.
  Если запасы долго не меняются, включи обратно: `gh workflow enable stash.yml`.
- Держать постоянно работающего бота на Actions — серая зона в правилах GitHub. Если нужны мгновенные ответы,
  используй локальный режим.
